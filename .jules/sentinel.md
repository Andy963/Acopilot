## 2025-02-27 - [Fix Command Injection in Terminal Shell Checks and Dependency Installation]
**Vulnerability:** Shell execution methods (`child_process.exec` and `execSync`) were being used with unsanitized, user-provided inputs (`shellPath` and directory prefixes) in `executeCommandShells.ts` and `DependencyManager.ts`. An attacker or malicious configuration could use shell metacharacters to perform command injection.
**Learning:** Even internal utility functions like checking if a shell exists or installing a local dependency can be vectors for command injection if they rely on shell evaluation. Also, when switching to `execFile` on Windows to avoid the shell, care must be taken for `.cmd` executables (like `npm.cmd`), which require `shell: true` to execute.
**Prevention:** Always use `child_process.execFile` or `child_process.spawn` with an arguments array, rather than constructing full command strings for `exec`. For Windows `.cmd` files, safely enable the shell but keep passing arguments as an array to allow Node to properly escape them.
